# 00. HTML 소개 및 개념 설명

## HTTP (Hypertext Transfer Protocol)

- 포트: 80 / 전송 계층 프로토콜: TCP
- 웹사이트 브라우징 프로토콜
- 웹서버에 웹페이지 정보를 요청(request)하고 웹서버는 응답(response)
- HTML(Hypertext Markup Language)을 사용하여 정보 전달
- 데이터가 텍스트로 전달되기 때문에 보안이 취약

## HTTPS (Hypertext Transfer Protocol Secure)

- 포트: 443 / 전송 계층 프로토콜: TCP
- 암호화를 사용한 HTTP 프로토콜
- 웹서버로부터 웹페이지 정보를 요청하고 받아옴
- HTML(Hypertext Markup Language) 사용
- 데이터가 암호화되어 전달되기 때문에 보안이 좋음
