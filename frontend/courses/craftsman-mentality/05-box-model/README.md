# 05. 박스 모델

## 박스 모델

박스 모델은 웹 페이지에서 요소가 차지하는 공간을 설명하는 모델입니다.
각 HTML 요소는 네 가지 주요 부분으로 구성됩니다.

- content (내용)
- padding (패딩)
- border (테두리)
- margin (마진)

## 사이즈 설정 (px, %, em, rem, vw, vh)

- **픽셀 (px)**: 화면에서의 절대적인 크기를 나타냄
- **백분율 (%)**: 부모 요소에 상대적인 크기를 나타냄
- **em**
  - 요소의 폰트 크기에 상대적인 크기를 나타냄
  - 부모 요소의 폰트 크기가 16px이면 1em은 16px을 나타냄
- **rem**: 루트 요소(보통 `<html>` 요소)의 폰트 크기에 상대적인 크기를 나타냄
- **vw, vh**
  - vw: 뷰포트의 너비에 상대적인 크기를 나타냄
  - vh: 뷰포트의 높이에 상대적인 크기를 나타냄
