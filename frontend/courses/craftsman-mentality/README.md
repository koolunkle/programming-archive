> YouTube 채널 **크래프트맨 멘탈리티**의 강의를 학습하며 작성한 실습 코드와 정리 노트입니다.

| 챕터 | 주제 | 내용 |

| [02-html-forms](02-html-forms) | HTML 간단한 양식 작성 | 텍스트/비밀번호 입력, 라디오 버튼, 체크박스, 드롭다운 |

## 실행 방법

각 `.html` 파일을 브라우저에서 열어 실행합니다. 동일한 이름의 `.css` 파일이 함께 적용됩니다.
